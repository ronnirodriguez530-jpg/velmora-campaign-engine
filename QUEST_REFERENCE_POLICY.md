# Velmora Quest Reference Learning Policy

Velmora may study why successful quests work, but it does not copy or lightly reskin another game's quest content.

## Permitted reference learning

- Record bibliographic provenance for an analyzed source.
- Extract abstract functions such as emotional promise, pressure, structural turn, choice shape, failure motion, and delayed consequence.
- Distill general design checks and failure warnings.
- Combine patterns from at least three distinct sources before applying them to a generated quest.
- Realize the resulting structure only through Velmora's current canon, characters, factions, locations, mechanics, and campaign state.

## Prohibited material

- Dialogue, scripts, quest logs, extracted game data, maps, images, audio, or other source assets.
- Source characters, names, factions, lore, named items, or recognizable set pieces.
- A source quest's distinctive scene sequence or twist with cosmetic substitutions.
- Source passages stored for retrieval or model training.
- Any reference treated as new Velmora canon without explicit approval.

## Repository rule

Every approved source, distilled pattern, transformation rule, evaluator, and test belongs in this repository. Chat discussion and model memory are not authoritative project storage.

The initial pattern file contains only original Velmora quest-contract principles. Observational analyses of individual games will be added in later reviewed checkpoints with source provenance and no copied source text.
